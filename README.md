# Мої нотатки (клієнт)

React + Vite фронтенд для API нотаток.

## Запуск

```bash
npm install
cp .env.example .env   # за потреби змініть VITE_API_URL
npm run dev
```

Бекенд має працювати на `VITE_API_URL` (за замовчуванням `http://localhost:3001`).

## Скрипти

- `npm run dev` — розробка
- `npm run build` — збірка
- `npm run lint` — ESLint
